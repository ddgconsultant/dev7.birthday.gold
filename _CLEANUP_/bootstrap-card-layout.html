Quick Reference - Bootstrap 5 Classes Used

Grid Classes:
  • container-fluid - Full width container
  • container - Centered container with max-width
  • row - Grid row wrapper
  • col-12 - Full width on all screens
  • col-md-8 - 66.67% width on medium+ screens
  • col-md-6 - 50% width on medium+ screens
  • col-md-4 - 33.33% width on medium+ screens
  • g-4 - Gutter spacing between columns
  • justify-content-center - Center columns
Card & Utility Classes:
  • card, card-header, card-body
  • h-100 - Height 100% (equal height cards)
  • mb-5 - Margin bottom spacing
  • py-4 - Padding vertical
  • w-100 - Width 100%
  • btn btn-primary - Primary button
  • btn btn-outline-primary - Outline button
  • text-primary - Primary text color
