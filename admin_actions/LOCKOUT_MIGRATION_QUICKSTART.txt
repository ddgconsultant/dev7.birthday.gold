NEW TABLE STRUCTURE
================================================================================

bg_lockout (Parent - Current State):
-----------------------------------
- id, ip, type, session_id, start_dt, expire_dt, create_dt, modify_dt, status
- first_violation_dt ← NEW
- last_violation_dt ← NEW
- total_violations ← NEW
- lockout_level ← NEW (1-18, represents 2^level minutes)

bg_lockout_history (Child - Full Audit Trail):
----------------------------------------------
- All bg_lockout fields PLUS:
- parent_id (references bg_lockout.id)
- lockout_minutes (calculated duration)
