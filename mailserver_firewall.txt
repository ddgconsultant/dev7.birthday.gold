> what isthe "1_2_3_4" in the name? 

● The 1_2_3_4 is the IP address with dots replaced by underscores.

  For example:
  - IP 45.148.10.52 becomes rule name MailFirewall_Block_45_148_10_52
  - IP 91.92.242.87 becomes rule name MailFirewall_Block_91_92_242_87
  - Subnet 45.148.10.0/24 becomes MailFirewall_Block_45_148_10_0_24

  Windows Firewall rule names can't contain dots or slashes, so we replace
  them with underscores using:
  $IP -replace '[./]', '_'

  So a permanent block for 45.148.10.52 would be named:
  MailFirewall_Block_45_148_10_52_PERM
